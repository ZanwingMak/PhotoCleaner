Privacy posture

Your photos stay where they belong.

RollKeep processes your library locally. App updates use GitHub Releases and optional support payments use Apple. Deletion always requires iOS system confirmation.

  • No photo uploads
  • Native iOS permission prompts
  • Open-source SwiftUI project

Source, releases, and support

One project. Every feature, free.

Get release builds or build the current source with Xcode. Report issues and contribute in ZanwingMak/PhotoCleaner, the only maintained repository. Optional one-time support is available in Settings; every feature stays free.
